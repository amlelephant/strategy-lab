Running from the code

This page runs a strategy exactly as its file declares it. Parameters are chosen in the file, and sweeps run in the terminal.

One strategy

Every strategy file ends with a __main__ block. Run it as a module, so its relative imports resolve. 

python -m lab.strategies.hundred_day_mov_avg

The two calls

from lab import backtest, sweep

backtest(HundredDayMovAvg, data="market_spy.csv", symbols="SPY")
backtest(HundredDayMovAvg, symbols="SPY", window=200)
sweep(HundredDayMovAvg, symbols="SPY", window=[50, 100, 200])

Why parameters are not on the page

A parameter value is a fact about a strategy's file. The moment a form can change one, the file stops being the answer to "what does this strategy do", and two runs of the same strategy stop being comparable. The interface offers what belongs to a run — which data, which universe, which frictions — and links to the file for the rest.

A sweep prints its grid and its verdict to the terminal and is never saved. The best Sharpe out of many tries is mostly a measurement of how many tries you had, which is a number to read beside the code that produced it, not to publish on a page. Read verdict(), not row one.

The command line

python run.py list
python run.py backtest stat_arb --symbols KO,PEP
python run.py sweep mean_reversion --symbols KO,PEP,XOM,CVX
python run.py fetch AAPL MSFT --start 2020-01-01 --end 2024-12-31
python run.py fetch-market
python run.py serve

fetch-market writes the two series every result is measured against — the S&P 500 and the 13-week T-bill.
